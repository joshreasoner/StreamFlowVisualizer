# Quick Command Reference

## Push to GitHub

Once you've created a repository on GitHub, run these commands in PowerShell:

```powershell
cd C:\Projects\Tinkering

# Add remote repository
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git

# Push to main branch
git push -u origin main

# Verify remote
git remote -v
```

## Local Git Commands

```powershell
# Check status
git status

# View commits
git log --oneline

# Make changes
git add .
git commit -m "Your message"
git push

# Create a new branch (optional)
git checkout -b feature-name
git push -u origin feature-name
```
